# MYBOARD.AI — правила Claude Code
Источники истины: `docs/TECHNICAL_SPEC.md`, `docs/ROADMAP.md`, `docs/ARCHITECTURE_DECISIONS.md`.
1. Не делай весь продукт одним изменением. Только одна маленькая задача за раз.
2. Перед кодом изучи контекст, предложи план, список файлов, риски и тесты. Жди одобрения.
3. Не меняй стек и архитектуру без ADR и согласования.
4. MVP не включает 3D: никаких 3D API, viewer, STL/3MF, 3D-таблиц. Studio 3D — будущая стадия.
5. Платежи, права, лимиты и модерация проверяются на сервере.
6. Секреты не помещать в Git, клиентский код или логи.
7. Не делать production deploy, destructive migration, удаление данных и платежные операции без подтверждения.
8. Не добавлять зависимости без объяснения пользы, альтернатив и рисков.
9. После изменений запускать lint, typecheck и релевантные тесты; проверять diff.
10. Если документы противоречат друг другу — остановись и сообщи.
После задачи отчитайся: что изменено, файлы, проверки, риски, следующий маленький шаг.
