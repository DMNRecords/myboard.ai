# Glossary
- Game Project — проект одной игры.
- Game Schema — структурированное версионируемое представление правил, поля, карт, жетонов и assets.
- AI Designer — диалоговый процесс создания игры.
- Entitlement — серверное право на функцию/квоту.
- Concept Preview — недорогой текстовый план будущей игры, не готовый продукт.
- Print Profile — стандарт размеров, вылетов, safe zones и параметров экспорта.
- MYBOARD STUDIO 3D — будущий модуль печатных миниатюр, исключён из MVP.
