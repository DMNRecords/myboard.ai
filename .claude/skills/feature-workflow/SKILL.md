---
name: feature-workflow
description: Use when planning or implementing a MYBOARD.AI feature; enforces small staged tasks, acceptance criteria and tests.
---
1. Read CLAUDE.md and relevant spec.
2. Define user outcome and non-goals.
3. In Plan Mode inspect code and propose minimal implementation.
4. List files, data changes, security concerns and tests.
5. Wait for approval.
6. Implement one vertical slice.
7. Run lint, typecheck, tests and inspect diff.
8. Update roadmap/docs.
9. Report changes, checks, risks and next task. Never implement 3D in MVP.
