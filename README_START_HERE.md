# Start here
1. Создай пустой GitHub-репозиторий `myboard-ai`.
2. Распакуй архив в корень репозитория.
3. Открой папку проекта в терминале и запусти `claude`.
4. Первым сообщением попроси Claude прочитать `CLAUDE.md` и документы, проверить комплектность и задать вопросы по ADR-001. Пока не писать приложение.
5. После подтверждения архитектуры попроси план Stage 0.
6. Двигайся по одной небольшой задаче; проверяй diff и тесты; делай логические Git commits.

В архиве есть ТЗ, roadmap, ADR, glossary, CLAUDE.md, узкие subagents и две skills.
